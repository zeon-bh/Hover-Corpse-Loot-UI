# Hover Corpse Loot UI (S.T.A.L.K.E.R. Anomaly / GAMMA)

A sleek, customizable Quality-of-Life HUD mod for **S.T.A.L.K.E.R. Anomaly (1.5.2 / 1.5.3 Modded Exes)** and **G.A.M.M.A.** that displays a loot preview window when hovering over dead Stalker corpses, complete with optional **Mouse-Wheel Quick-Looting**, **Utjan Item UI Overlays**, and **Redone FDDA** animation support.

---

## Various Customization Options

* **Real-Time Corpse Loot Preview:** View a corpse's inventory icons on the HUD without opening the full-screen inventory window.
* **Three Dynamic UI Layouts (MCM Selectable):**
  * **Minimal:** Ultra-clean horizontal strip.
  * **Tactical:** Authentic 2D Tetris inventory grid with header (Faction Patch, Name, Rank, and Faction).
  * **Compact:** Uniform `1x1` square grid that proportionally scales weapons and outfits into neat, compact cells.
* **Persistent `(Looted)` Status Indicator:**
  * Displays a customizable bright green indicator (`(Looted)`, `[LOOTED]`, `[v]`, `[+]`, or `[UNSEARCHED]/[LOOTED]`) in the header once a corpse has been searched.
* **Full Utjan Item UI Improvements Integration (Individually Toggleable in MCM):**
* **Interactive Mouse-Wheel Quick-Looting:**
  * **Scroll to Select:** Rolling the mouse wheel highlights items in visual reading order (top-to-bottom, left-to-right).
  * **Quick Transfer:** Left-Click (or custom MCM keybind) to take the selected item/stack; Right-Click (or custom MCM keybind) to **Loot All**.
* **Fully customizable in MCM**
  * Fully customize keybinds for quick looting, Hover UI Window, selection color, window opacity in MCM.

---

## Requirements

* **S.T.A.L.K.E.R. Anomaly 1.5.2 / 1.5.3** with **Modded Exes**
* **Mod Configuration Menu (MCM)** (Recommended for full UI and keybind customization).
* *(Optional)* **Utjan's Item UI Improvements** (Used for part condition dots and item badges).
* *(Optional)* **Liz's Redone FDDA** (Used for one-handed body-search animations during quick-looting).

---

## Installation

1. Download the repository archive (or clone directly into your Mod Organizer 2 `mods` directory).
2. Install and enable via **Mod Organizer 2 (MO2)**.
3. Load at bottom of your mod list just to be safe. (should have no script conflicts, all of them are monkey patched.) 
3. Customize the layout, overlays, colors, and keybinds in **MCM -> Hover Corpse Loot**.
